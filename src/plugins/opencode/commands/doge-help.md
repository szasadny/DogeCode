Show the doge quick-reference card.

| Command | What |
|---|---|
| `/doge` | Activate at default level (full) |
| `/doge lite` | Light compression — ~30% tokens dropped |
| `/doge ultra` | Maximum compression |
| `/doge wenyan[-lite\|-ultra]` | Classical Chinese compression |
| `/doge off` | Deactivate |
| `/doge-commit` | Terse commit message |
| `/doge-review` | One-line review findings |
| `/doge-compress <file>` | Compress a Markdown file |
| `/doge-stats` | Lifetime token-savings |

Natural language also works: "turn on doge", "stop doge", "normal mode".

Code, commits, security warnings: doge drops out automatically.
